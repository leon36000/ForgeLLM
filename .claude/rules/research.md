# Research rules

- Use primary sources and canonical URLs.
- Pin repository commits and paper versions when a claim informs implementation.
- Update `research/claims.yaml` with scope, evidence and reproduction status.
- Do not treat README speedups, stars or adoption as reproduced performance.
- Run `forgellm-governance validate` before completion.
