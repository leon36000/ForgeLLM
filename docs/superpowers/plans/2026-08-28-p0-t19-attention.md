# P0-T19 implementation plan

Companion to `docs/superpowers/specs/2026-08-28-p0-t19-attention-design.md` — see that file for
the numerical derivations and scope rationale; this is the task-by-task checklist.

1. **Rust**: add `ReferenceError::UnsupportedQueryCount`, `transpose`, `attention_decode_single_query`
   to `crates/forgellm-reference/src/lib.rs`. Write failing tests first
   (`crates/forgellm-reference/tests/reference_ops.rs` for `transpose`; a new
   `crates/forgellm-reference/tests/attention.rs` for the composed op and its error paths),
   confirm RED, then implement to GREEN.
2. **Python oracle**: add `transpose_exact`, `attention_oracle` to
   `src/forgellm_governance/reference_oracle.py`, docstring-deriving the combined tolerance per
   the spec. Add fixture cases to `scripts/generate_reference_oracle_fixture.py` (at least one
   `context_len == 1` and one `context_len > 1` case, magnitudes kept inside the mechanically
   checked f64-exact range).
3. **Fixture + Rust contract test**: regenerate
   `crates/forgellm-reference/tests/fixtures/reference_ops_oracle.json`/`.sha256`; extend
   `crates/forgellm-reference/tests/support/mod.rs` only if the fixture schema needs a new field
   (expect not to, if the case shape matches the existing tensor-in/tensor-out/tolerance
   convention); extend `reference_ops_oracle_contract.rs` to dispatch `"transpose"` and
   `"attention"` fixture cases.
4. **Python tests**: `tests/test_reference_oracle.py` additions for `transpose_exact` and
   `attention_oracle`, including the adversarial near-tie and randomized-stress checks the spec
   requires, and a re-run confirmation of the existing Ziv-escape regression tests (unchanged,
   must still pass).
5. **Self-audit**: run the adversarial/randomized battery from the spec's "Adversarial
   self-audit plan" section myself, before requesting any review. Fix anything found and
   document it transparently, exactly like P0-T18.
6. **Task packet**: `tasks/open/P0-T19-single-query-attention.yaml`, schema-validated.
7. **Local verification**: `make ci` green (ruff, validators, pytest, speculative, Rust
   fmt/clippy/test, fixture `--check`, sha256sum -c) before any push.
8. **Independent review**: spawn an independent review agent with no access to this session's
   reasoning, specifically asked to adversarially re-derive the tolerance and hunt for a
   margin/budget-direction bug the way P0-T18's reviewer did — that is the exact bug class this
   codebase has already shown it's vulnerable to.
9. Fix any findings, re-verify, push, open PR, run collision check again, blind trio, merge —
   following the exact PR #85/#86 pattern.
10. Close the task packet lifecycle in a small follow-up PR, mirroring #84/#86.
